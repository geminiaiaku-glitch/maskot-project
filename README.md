# Unduh Maskot / Momo untuk Windows

[**Klik di sini untuk mengunduh Maskot-win-x64.zip**](https://github.com/geminiaiaku-glitch/maskot-project/raw/refs/heads/downloads/Maskot-win-x64.zip)

1. Setelah selesai diunduh, klik kanan ZIP lalu pilih **Extract All / Ekstrak Semua**.
2. Buka folder hasil ekstraksi.
3. Klik dua kali **Maskot.exe**. Tidak perlu memasang .NET atau alat coding.

Target Windows 11 64-bit. Paket ini adalah versi percobaan yang dibuat di cloud.
32 tes logika lulus dan kompilasi Windows berhasil, tetapi UI, taskbar, media,
dan interaksi desktop belum diuji langsung di Windows. Build belum ditandatangani.
Jika Windows menampilkan pemblokiran atau aplikasi mengeluarkan pesan kesalahan,
kirim pesan atau tangkapan layarnya ke percakapan Codex untuk diperiksa.

[Kode proyek dan dokumentasi](https://github.com/geminiaiaku-glitch/maskot-project/tree/main)

Checksum SHA256 tersedia pada `Maskot-win-x64.zip.sha256`.
