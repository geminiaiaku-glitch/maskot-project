MASKOT / MOMO — VERSI PERCOBAAN 0.4

Untuk Windows 11 64-bit.

Sebelum memperbarui, klik kanan Momo lama atau ikon Momo di dekat jam Windows,
lalu pilih Keluar. Catatan dan tugas tidak perlu dihapus.

1. Klik kanan file ZIP yang sudah diunduh, lalu pilih "Extract All" / "Ekstrak Semua".
2. Buka folder hasil ekstraksi.
3. Klik dua kali Maskot.exe. Jangan menjalankannya dari dalam tampilan ZIP.

Tidak perlu memasang .NET atau alat coding. Simpan folder hasil ekstraksi di
tempat tetap agar pengaturan jalankan saat login tetap menunjuk ke file yang benar.

Cara menggunakan:
- Klik tubuh Momo: buka atau tutup panel fitur.
- Klik kanan Momo: Jalan-jalan, Diam di sini, Pengaturan, dan Keluar.
- Seret ke tengah atas layar, lalu lepas pada penanda: menjadi notch.
- Tarik badan notch ke bawah: kembali menjadi maskot.
- Escape saat menyeret: batalkan perpindahan.
- Jatuhkan file ke tubuh Momo atau notch: simpan pintasan di file shelf.
- Untuk menutup sepenuhnya, pilih Keluar melalui menu atau ikon tray.

Momo 0.3 memiliki animasi kaki/ekor/kedip/napas dan tetap tampil di atas fullscreen
secara default. Opsi menyembunyikan saat fullscreen bisa diaktifkan di Setelan.

Ini build percobaan yang belum ditandatangani. Tes core dan regresi WPF otomatis
pada Windows runner dijalankan. Taskbar, media nyata, klik transparan, multi-monitor
dan perilaku di perangkat Windows 11 pengguna masih perlu pengujian manual.

Jika muncul kesalahan, kirim tangkapan layar atau salin pesan kesalahannya ke chat.
Jika Windows memblokir aplikasi, kirim pesan yang muncul agar dapat diperiksa.

Data catatan/tugas/pengaturan: %LOCALAPPDATA%\Maskot\state.json
Log kesalahan aplikasi: %LOCALAPPDATA%\Maskot\errors.log

Baca TESTING.md dan WINDOWS-ACCEPTANCE.md untuk rincian status pengujian.

KARAOKE / LIRIK
Klik kanan Momo → Lirik & karaoke → Aktifkan lirik online, lalu putar lagu.
Judul/artis/durasi lagu dikirim ke LRCLIB. Notch menampilkan lirik; Momo bernyanyi
dengan mic dan balon lirik. Jika lirik tidak tersedia, Momo menunjukkan wajah dan
gestur bingung tanpa tulisan. Mic hanya muncul saat musik diputar, termasuk bila
lirik online dimatikan. Saat jeda/berhenti, mic ikut hilang.
Tidak ada rekaman mikrofon atau suara tambahan.
Teks tanpa timestamp diberi label tanpa sinkronisasi.

Versi 0.3.2 mengurangi pekerjaan berulang saat musik berjalan dan memperkuat
pemulihan data cadangan. Runtime .NET diperbarui ke 10.0.14.

NOTCH INTERAKTIF
Klik kanan Momo → Jadi notch. Dekatkan kursor untuk membuka panel, lalu gunakan
panah kiri/kanan atau ikon bawah untuk Musik, Fokus, Ruang dan Setelan.
Ikon lirik membuka tampilan musik dan lirik berdampingan. Jauhkan kursor untuk
menutup preview; saat mengetik catatan panel tetap terbuka. × atau Escape menutup.
Seret judul panel notch ke bawah untuk kembali menjadi Momo; Escape membatalkan drag.
