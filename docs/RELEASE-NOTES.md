Versi percobaan pertama Maskot / Momo untuk **Windows 11 x64**.

## Cara mencoba

1. Pada bagian **Assets**, unduh **Maskot-win-x64.zip**.
2. Klik kanan file unduhan dan pilih **Extract All / Ekstrak Semua**.
3. Buka folder hasil ekstraksi dan klik dua kali **Maskot.exe**.

Tidak perlu mengunduh **Source code**, memasang .NET, atau menjalankan perintah coding.
Jika GitHub meminta login, gunakan akun yang memiliki akses ke repositori ini.

Maskot berjalan/diam, drag dan docking ke notch, panel media Windows, Pomodoro,
catatan, tugas, serta file shelf sudah diimplementasikan. Aset Momo masih sementara.

Tes logika dan kompilasi dapat diverifikasi dari workflow **Windows build and core
tests**. Build ini **belum melalui pengujian desktop Windows secara menyeluruh**:
taskbar auto-hide, fokus, click-through, media nyata, tray, dan DPI perlu dicoba
langsung. Build belum ditandatangani. Windows 10 dan ARM64 belum diuji.

Jika muncul pesan kesalahan atau pemblokiran Windows, kirim pesan/tangkapan layarnya
ke percakapan Codex agar bisa diperiksa.
